## 二、BUG 发现与修复

### BUG-001：登录后 404（🔴 严重 — 已修复 ✅）

**问题描述：**
所有用户登录后自动跳转到 `/dashboard/analytics`，该路由在 backend 访问模式下不存在（实际路由为 `/dashboard/analysis`），导致 404 页面。

**根本原因（双重问题）：**
1. 后端 `GET /api/v1/user/info` 返回 `homePath: "/dashboard/analytics"`
2. 后端 `GET /api/v1/menus/me` 注册的分析页路由路径为 `/dashboard/analysis`
3. 前端 Vben 核心默认 `defaultHomePath: '/analytics'` 也未覆盖
4. 三者不一致导致登录重定向必定 404

**修复方案（3 文件，纵深防御）：**

| 文件 | 修改内容 |
|------|----------|
| `apps/src/preferences.ts` | 新增 `defaultHomePath: '/dashboard/analysis'` |
| `apps/src/store/auth.ts` | `fetchUserInfo()` 中将 `/dashboard/analytics` 映射为 `/dashboard/analysis` |
| `apps/src/router/guard.ts` | 两处 `homePath` 引用增加同样的兼容映射 |

**验证结果：**
- 修复后重新登录 → URL 正确跳转到 `/dashboard/analysis`
- 页面标题显示「分析页 - AI 智能客服管理平台」
- Dashboard 内容正常渲染（4 指标卡片 + 趋势图 + 雷达图 + 状态饼图 + 标签分布图）
